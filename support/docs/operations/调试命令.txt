# 开发调试命令

所有命令均在仓库根目录执行。

## 前端检查

前端使用浏览器原生 ES Modules，不需要安装依赖、启动 Vite 或生成 `dist`。

```powershell
Set-Location Business/ReferenceRAG.Business/wwwroot
node check.mjs
node --test
```

## Web 端

```powershell
dotnet run --project Host/ReferenceRAG.WebHost
```

## 桌面端

桌面端仅支持 Windows，并要求系统已安装 WebView2 Runtime。

```powershell
dotnet run --project Host/ReferenceRAG.DesktopHost
```

## 调试配置

本机配置放在 `support/config/local/appsettings.json`，也可以通过环境变量指定独立配置根目录：

```powershell
$env:REFERENCERAG_CONTENT_ROOT = 'E:\ReferenceRAG-Local'
dotnet run --project Host/ReferenceRAG.WebHost --configuration Debug
```

WebHost 与 DesktopHost 会对数据目录加单写入者锁，不要让两个宿主同时使用同一数据目录。
